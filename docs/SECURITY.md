# 安全说明

职面 AI 在设计和实现上内置了以下安全能力，适合作为 AI 应用安全实践参考。

## 用户认证

- 手机号验证码注册：6 位随机验证码，5 分钟过期，使用后立即失效。
- 密码存储：PBKDF2-HMAC-SHA256 + 随机盐 + 10 万次迭代。
- JWT：HS256 签名，默认 30 分钟过期，业务接口统一中间件校验。

## 防刷与限流

- 全局限流：每 IP 每分钟 120 次（滑动窗口）。
- 验证码限流：每手机号每分钟 5 次。
- 登录失败锁定：连续 5 次失败锁定 15 分钟。

## 数据隔离与合规

- 所有业务数据按用户隔离，接口通过 JWT 注入 user_id。
- 支持账号数据导出与一键注销删除。
- 静态资源（PDF、头像）由后端统一提供。

## AI 内容安全

- 简历生成链路内置风控核查，拦截无中生有的硬技能与离谱数据。
- 面试提示由系统 Prompt 约束，避免诱导输出。

## 上报安全漏洞

请勿在公开 Issue 中提交真实密钥或用户数据。发现安全问题请通过 GitHub Security Advisory 或仓库维护者私下联系。
